Platform & Administration

Where configuration lives, which tool does what, and how data reaches the rest of SAP SuccessFactors. In a hands-on exam, knowing which tool owns an outcome saves more time than anything else.

Quiz this topic

Key concepts

  • Admin Center vs. Provisioning. Admin Center is the customer's day-to-day administration area (permissions, picklists, business rules, data). Provisioning is the back end, restricted to SAP and certified partner consultants: data model XML uploads, company settings and scheduled jobs such as HRIS Sync.
  • Finding tools fast. Use the action search in the header or the tool search in Admin Center and type the tool name, e.g. Manage Permission Roles. Bookmark it as a favourite if you use it often.
  • Check Tool. Runs validation checks on the configuration, shows the issues found and offers a Quick Fix for some of them. It can also prepare information for an SAP support incident.
  • Upgrade Center. Lists optional upgrades and new features that an administrator can review and apply in the instance.
  • Instance Synchronization Toolkit. Copies configuration artifacts such as permission roles, MDF object definitions and picklists from a source instance (e.g. test) to a target instance (e.g. production).
  • Picklist Center. The central tool to create picklists and maintain their values, labels, status and parent-child relationships for cascading picklists.
  • HRIS Sync. A scheduled job that copies Employee Central data (e.g. from Job Information) into the basic user data that other modules such as Performance & Goals use. Which fields are synced is controlled by HRIS sync mappings in the Succession Data Model.

Common traps

  • Data model XML upload and scheduled-job creation happen in Provisioning, not Admin Center.
  • Picklists are maintained in Picklist Center, not in the data model.
  • HRIS Sync runs from Employee Central to user data, not the other way round.

Practice tasks

Do these in a practice or demo instance. Each one ends with how to prove the outcome, just like in the exam.

Health check before you start

Outcome: You know which Employee Central configuration checks fail in your instance and have fixed at least one with a Quick Fix.

Hints
  1. Open the Check Tool via the action search.
  2. Filter on the Employee Central application and run the checks.
  3. Open a failed check, read the details and apply the Quick Fix if one is offered.

Prove it: Re-run the same check. It now passes, or you can explain why the remaining failure is expected.

A new cascading picklist

Outcome: A picklist WorkSchedulePattern with three values exists, and each value is shown only for its parent value in a second picklist.

Hints
  1. Create both picklists in Picklist Center.
  2. Give each child value a parent picklist value.
  3. Keep the values Active.

Prove it: Open the picklist in Picklist Center and show the parent values next to each child value.

Find what's new

Outcome: You can name two optional features currently offered for Employee Central in your instance and what each one changes.

Hints
  1. Open Upgrade Center.
  2. Read the detail page of an Employee Central upgrade before applying anything.

Prove it: Write down the two feature names and whether they can be undone after applying.
